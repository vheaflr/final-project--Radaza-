# User Stories
<!--
A user story describes ONE thing a user wants to do, from their point of view.
Write 3–5 stories using this format:

As a [type of user], I want to [do something] so that [I get this benefit].

Tips:
- Give each story an ID (US1, US2...). You'll use these IDs in acceptance-criteria.md.
- One action per story. If you see "and" in the middle, split it into two stories.
- The "so that" part is the reason. If you can't think of one, you may not need that feature.
- Put your most important story first. That's the one you'll build first.

Example:
US1: As a customer, I want to see today's menu with prices so that I can decide what to order.

US - User Story
-->

### Feature: Office Selection & Search 
US1: As a student, I want to browse, search, and filter available campus offices, so that I can quickly find the specific office I need to visit. 

US2: As a student, I want to view an office's details before joining its queue, so that I make sure I am prepared before getting in line.

US3: As a student, I want to clearly see whether an office is currently Open, Closed, or Full, so that I do not try to join an unavailable queue.

### Feature: Live Queue Status Display 
US1: As a student, I want to view the current queue status of a selected office, so that I know how many people are ahead of me and how long I will have to wait. 

US2: As a student, I want to see the ticket number currently being served alongside the next numbers in line, so that I can track how fast the queue is moving.

US3: As a student, I want the queue display to update live without reloading the whole page, so that I always see accurate queue progress.

### Feature: Virtual Queue Number Generation 
US1: As a student, I want to request and receive a virtual queue number after submitting my required details, so that I can hold my spot in line without physically standing in a crowd. 

US2: As a student, I want my active virtual ticket to stay saved even if I refresh or reopen the browser, so that I do not lose my queue number.

US3: As a student, I want to cancel my active queue number if my plans change, so that I free up my spot for other students.
